Documentación Oficial: API de Pedidos para Saint Enterprise ERP

Especificación técnica para la sincronización de pedidos entre la tienda web de Heladería Hollywood y el software Saint Enterprise ERP (SQL Server). Adaptado para 10 sedes físicas con atención y cierre por WhatsApp.

1. Parámetros Generales de Conexión

Protocolo REST API (JSON sobre HTTPS)
URL Base https://pedidos.helaholly.com (o dominio asignado en Hostinger)
Método de Autenticación Encabezado HTTP: x-api-key (o Authorization: Bearer)
API Key Asignada holly_sistema_sec_2026
Formato de Fechas Estándar ISO 8601 UTC (ejemplo: 2026-09-21T19:20:00.000Z)
Codificación UTF-8 estricto

2. Catálogo de Endpoints

GET /api/sistema/health

Descripción: Ping de conectividad. Permite verificar que el servidor está online y que la clave de seguridad es correcta.

Encabezados requeridos: x-api-key: holly_sistema_sec_2026

// Respuesta Exitosa (200 OK):
{
  "success": true,
  "service": "Hollywood Pedidos API - Sistema",
  "status": "online",
  "timestamp": "2026-09-21T19:22:01.079Z"
}

GET /api/sistema/orders

Descripción: Obtiene la lista de pedidos realizados por los clientes en la tienda web.

Filtros opcionales (Query Params):

  • ?status=pending: (Recomendado) Retorna únicamente pedidos pendientes por facturar.
  • ?status=facturado: Retorna pedidos que ya fueron sincronizados o facturados.
  • ?status=all: Retorna todos los pedidos sin filtrar.
  • ?store=5 de Julio: Filtra por el nombre de la sede de la heladería.
  • ?limit=50: Limita el número de resultados.
// Petición cURL:
curl -H "x-api-key: holly_sistema_sec_2026" \
     "https://pedidos.helaholly.com/api/sistema/orders?status=pending"

PATCH /api/sistema/orders/{id}

Descripción: Permite al integrador local de Saint actualizar el estado del pedido en dos momentos: al ingresarlo en caja (en_caja) y al totalizar la factura fiscal (facturado).

Encabezados requeridos: Content-Type: application/json | x-api-key: holly_sistema_sec_2026

// Momento 1: Registro en Saint ERP (Se imprime comanda de cocina y reserva stock):
PATCH /api/sistema/orders/ORD-1726912345-ABCD HTTP/1.1
Host: pedidos.helaholly.com
x-api-key: holly_sistema_sec_2026
Content-Type: application/json

{
  "status": "en_caja",
  "saintOrderNumber": "PED-000412",
  "notes": "Comanda registrada en Saint ERP y enviada a barra de preparación."
}

// Momento 2: Totalización en Caja Fiscal (Emisión de Factura Fiscal Tipo 'A' / 'C'):
PATCH /api/sistema/orders/ORD-1726912345-ABCD HTTP/1.1
Host: pedidos.helaholly.com
x-api-key: holly_sistema_sec_2026
Content-Type: application/json

{
  "status": "facturado",
  "invoiceNumber": "FAC-001245",
  "notes": "Factura emitida por Caja 1. Pago verificado en WhatsApp."
}

// Respuesta Exitosa (200 OK):

3. Diccionario de Datos

Campo Tipo Descripción
id String Identificador único del pedido en la tienda web.
createdAt ISO DateTime Fecha y hora exacta en la que el cliente hizo el pedido.
customer.name String Nombre completo del cliente.
customer.phone String Número telefónico o de WhatsApp para contacto.
customer.address String Dirección física de entrega (o retiro en tienda).
store String Nombre de la sede de Heladería Hollywood.
mode String delivery (a domicilio) o in-store (retiro en tienda).
items[].name String Nombre del producto helado.
items[].price Number Precio unitario en USD.
items[].quantity Integer Cantidad de unidades solicitadas.
items[].subtotal Number Subtotal del ítem (precio * cantidad).
items[].customization Object Sabores, capa mágica y toppings seleccionados.
subtotal Number Total en productos (USD).
deliveryFee Number Costo de delivery (0 si es retiro en tienda).
total Number Monto final total a cobrar y facturar (USD).
status String Estado: pending (pendiente), facturado, cancelado.

4. Ejemplo de Código para el Programador (C# / .NET)

using System;
using System.Net.Http;
using System.Threading.Tasks;

public class HollywoodSyncService {
    private static readonly HttpClient client = new HttpClient();
    private const string BASE_URL = "https://pedidos.helaholly.com";
    private const string API_KEY = "holly_sistema_sec_2026";

    // 1. Consultar pedidos pendientes
    public async Task ConsultarPedidosPendientes() {
        var request = new HttpRequestMessage(HttpMethod.Get, BASE_URL + "/api/sistema/orders?status=pending");
        request.Headers.Add("x-api-key", API_KEY);

        var response = await client.SendAsync(request);
        if (response.IsSuccessStatusCode) {
            string jsonResponse = await response.Content.ReadAsStringAsync();
            Console.WriteLine("Pedidos obtenidos: " + jsonResponse);
            // Deserializar JSON e insertar en la base de datos del sistema administrativo...
        }
    }

    // 2. Marcar pedido como facturado
    public async Task MarcarFacturado(string orderId, string invoiceNumber) {
        var content = new StringContent(
            $"{{\"status\": \"facturado\", \"invoiceNumber\": \"{invoiceNumber}\"}}",
            System.Text.Encoding.UTF8,
            "application/json"
        );
        var request = new HttpRequestMessage(new HttpMethod("PATCH"), BASE_URL + "/api/sistema/orders/" + orderId) {
            Content = content
        };
        request.Headers.Add("x-api-key", API_KEY);

        await client.SendAsync(request);
    }
}

5. Recomendaciones de Integración

  • Frecuencia de Consulta (Polling): Se recomienda consultar pedidos pendientes cada 60 a 120 segundos.
  • Trazabilidad: Se sugiere guardar el id del pedido web en la base de datos contable para evitar duplicados.
  • Soporte Técnico: Ante cualquier duda sobre la estructura o requerimiento de campos adicionales, contactar al equipo de desarrollo web.
